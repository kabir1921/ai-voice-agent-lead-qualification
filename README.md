# AI Voice Agent: Outbound Lead Qualification

Design of a bilingual (English and Hindi) outbound voice agent that screens inbound leads on the first call and hands qualified ones to a human.

## What was designed

- **Call flow:** opening, consent, qualifying questions, and a clear close
- **Agent instructions:** prompt design for GPT-4o covering tone, language switching between English and Hindi, and handling of off-script answers
- **Compliance guardrails:** boundaries on what the agent may say or ask, and when it must stop
- **Escalation paths:** defined triggers for transferring to a human or ending the call

## Stack

Vapi, GPT-4o

## Scope

This repository documents the design. It is a design and prompt-engineering project, not a deployed production system.
